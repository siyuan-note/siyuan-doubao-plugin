# 思源笔记 · 豆包插件

让豆包工作通过 MCP 直接读写你的思源笔记：搜索、阅读、编写、整理。

插件本体不保存任何笔记数据，所有读写都发生在你自己的思源内核上。

> 状态：开发中，尚未提交上架审核。

## 工作方式

- 传输：MCP Streamable HTTP，指向思源内核的 `/mcp`
- 鉴权：思源 API token，请求头 `Authorization: Token <token>`
- 组成：一个技能（教豆包怎么用这些工具）+ 一份 MCP 连接配置（工具和数据从这来）

## 使用前提

- 思源 3.8.x 及以上，且内核正在运行
- 豆包工作客户端，插件运行在「本地电脑」
- 已在思源「设置 → 鉴权 → API token」取得 token
- 当前工作空间的 MCP 能力开关已开启

## 已知限制

- 云电脑模式下 `127.0.0.1` 指向云主机，连不到你本机的思源
- 思源内核内置的 MCP 工具数量较多，模型存在选错工具的可能
- 插件包结构以豆包开放平台实际校验结果为准，本仓库文件可能调整
